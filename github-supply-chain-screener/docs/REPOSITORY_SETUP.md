# GitHub publishing checklist

1. Create an empty public repository named `github-supply-chain-screener` under `Digitalfrontiersman`.
2. Grant the Codex GitHub connection access to that repository, or install the GitHub app for the account/repository.
3. Push this local repository to GitHub.
4. Add the description and topics from [LAUNCH.md](LAUNCH.md).
5. Enable Discussions and branch protection for `main`.
6. Add a social-preview image and pin the repository on the GitHub profile.
7. Only add `FUNDING.yml` after deciding on a real sponsorship or funding destination.
