# Security policy

## Reporting a vulnerability

Do not publish exploit details, payloads, or suspected malicious release links in a public issue.

Email `Jonathan@digitalagebusiness.com` with:

- affected version or commit;
- a minimal, non-destructive reproduction;
- impact and recommended mitigation.

Do not include credentials, private data, or live malware. We will acknowledge reports promptly and coordinate disclosure before publishing a fix.

## Safe testing

Never execute unknown repositories or payloads to test this project. Use inert fixtures, a disposable environment, and minimal permissions.
