# Privacy

This skill operates on information a person chooses to share in the current conversation. It should keep only factual, task-relevant session state when the hosting product supports memory.

Do not request credentials, payment information, private health records, or unnecessary identifying information. Do not use another person's stated values or personal information to pressure, target, or manipulate them.

Users should review the privacy practices of the AI product hosting the skill; this repository does not operate a separate data-collection service.
