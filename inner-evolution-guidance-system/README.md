# Inner Evolution Guidance System

Reflective coaching that turns demonstrated priorities, beliefs, and attention into one grounded next action.

## What it does

This skill guides a seven-stage COMPASS conversation: clarify demonstrated priorities, observe the goal and beliefs, map a controllable action, propose credible connections, authenticate what is true, schedule a minimum action, and study the resulting proof.

It can draw carefully bounded practical lenses from Aristotle, values work, attention training, comparative wisdom, and Ma'at-inspired Egyptian symbolism. It treats all interpretations as suggestions for the user to validate.

## What it does not do

- It is not therapy, medical or mental-health treatment, a religious initiation, or a scientific claim about spiritual or historical ideas.
- It does not reproduce proprietary exercises, auditing, course procedures, or worksheets from any teacher, school, or organisation.
- It does not promise healing, manifestation, neurological rewiring, spiritual attainment, or guaranteed outcomes.

## Install

Copy this folder into your Codex skills directory, or install it from this repository using your preferred skill installer. The agent reads `SKILL.md` as its operating guide.

## First use

Ask the agent to help you turn a goal, habit, identity, or difficult decision into a small action that fits what you genuinely value. It will ask one main question at a time and end with an observable next step.
