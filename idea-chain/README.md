# IDEA CHAIN

Turn one rough seed into a short, causal chain of major ideas that reaches one clear goal.

IDEA CHAIN is built for businesses, products, campaigns, ads, pages, stories, events, offers, and concepts that need direction without a bloated brainstorm. Each major idea must unlock the next, so the result reads like a chain reaction rather than a pile of disconnected suggestions.

## Choose a mode

- **Fast Mode:** Move quickly from the supplied context to three strong links.
- **Pro Mode:** Add focused research, authoritative sources, verification, and a non-obvious insight.
- **God Mode:** Use deep multi-angle research, counterexamples, audience evidence, second-order effects, and pressure-testing before distilling the result.

If the prompt does not name a mode, IDEA CHAIN asks which mode to use before beginning.

## What makes it different

- Keeps the visible result to 3-5 major ideas.
- Makes every handoff explicit with `This unlocks -> ...`.
- Separates facts from inference when research is involved.
- Tests tension, originality, causality, weak assumptions, and compression.
- Expands only the selected link when the user asks to zoom in.
- Can use the approved chain as the creative spine for a brief, story, campaign, offer, page, or action plan.

## Example

```text
Use $idea-chain to turn this rough business idea into a clear concept.
```

Or select the mode immediately:

```text
Use $idea-chain in Pro Mode with a brutal reality check: create a launch concept for an AI workshop aimed at first-time founders.
```
