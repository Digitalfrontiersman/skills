# Public Release Notes

This initial public edition contains the general IDEA CHAIN conceptualization workflow, its Fast, Pro, and God research modes, optional intelligence controls, contract tests, privacy and security boundaries, installation path, and launch materials.

The release was reviewed for credentials, tokens, personal data, client or account details, private URLs, confidential workflow steps, and copied proprietary material. None are included.

God Mode requests the strongest reasoning configuration available to the current run but does not claim to change a host application's selected model or reasoning setting. Research depth remains subject to the tools, permissions, sources, and model available in the user's environment.

Before future releases, repeat the privacy and authority audit, validate `SKILL.md`, and confirm that all researched claims still require current source verification at runtime.

## Intentionally excluded

- Local installation paths and workspace artifacts.
- Private conversations, personal memory, client context, and unpublished plans.
- Credentials, account configuration, model entitlements, and connected-service settings.
- A bundled research corpus; Pro and God Modes must retrieve current sources at runtime.
