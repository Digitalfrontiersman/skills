# Public Release Check

## Reviewed scope

Portable, read-only Instagram Professional Dashboard audit guidance for autonomous agents.

## Checks completed

- No credentials, tokens, private URLs, account exports, screenshots, client data, or personal performance metrics included.
- No publishing, editing, deletion, messaging, payment, or permission-changing automation included.
- The workflow requires the user's authenticated browser session or a user-provided Insights export and keeps dashboard data private by default.
- Host-specific installation and approval guidance is included.
- `SKILL.md`, agent metadata, reference, public README, license, and root catalog entry are included.

## Intentionally excluded

- Real Instagram account handles, audit findings, dashboard screenshots, exports, and internal browser-session details.
- Any instructions that would bypass host permissions, Instagram login, CAPTCHAs, or approval controls.
